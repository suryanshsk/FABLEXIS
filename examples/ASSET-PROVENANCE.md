# Fablexis example asset provenance

The raster assets in the example projects are original deterministic artwork
generated locally with Pillow for this repository. They are not downloaded,
licensed from a third party, or derived from a stock-image collection.

| Asset | Projects | Type | Origin | Redistribution |
|---|---|---|---|---|
| `assets/editorial-photo.jpg` | `real-assets-demo`, `autonomous-idea-demo` | JPEG | Original geometric illustration generated by the project maintainer with Pillow | Permitted under the repository MIT license |
| `assets/transparent-orbit.png` | `real-assets-demo`, `autonomous-idea-demo` | Transparent PNG | Original abstract orbit illustration generated by the project maintainer with Pillow | Permitted under the repository MIT license |
| `assets/system-diagram.svg` | `real-assets-demo`, `autonomous-idea-demo` | SVG | Original local vector diagram authored for the examples | Permitted under the repository MIT license |

No fonts, icons, videos, or external media are bundled. Runtime typography uses
system fonts or a user-configured font path. The assets contain no external
URLs, downloaded content, logos, or embedded third-party metadata.
